# Recruiter Insights & Feedback Hub

Folder ini mengorganisir seluruh riset kebutuhan rekruter, audit feedback riil dari tech recruiter, dan checklist aksi untuk optimalisasi CV serta portofolio kandidat.

---

## Daftar Dokumen

| Dokumen | Deskripsi | Target Pembaca / Manfaat |
| :--- | :--- | :--- |
| **[`what-recruiters-need.md`](./what-recruiters-need.md)** | **Riset Komprehensif: Kebutuhan Recruiter & HR**<br>Riset bersumber primer (studi Ladders, dokumentasi ATS Greenhouse/Workday/Oracle, UU PDP, SE Menaker) dengan label tingkat bukti, mitos yang diluruskan, checklist CV dev/PM, panduan praktis (XYZ, submission note, anti-pattern), dan status CV yang ada. | Panduan strategis saat merancang atau merevisi struktur CV & portofolio. |
| **[`portfolio-feedback.md`](./portfolio-feedback.md)** | **Audit Riil Tech Recruiter untuk Profil Saepul Malik**<br>Ulasan otentik dari tech recruiter mengenai kekuatan, kekurangan yang memblokir submission, dan rekomendasi tiket perbaikan. | Sumber rujukan evaluasi objektif terhadap portofolio dan profil nyata saat ini. |
| **[`action-checklist.md`](./action-checklist.md)** | **Action Items & Checklist Pra-Kirim CV**<br>Checklist taktis untuk memastikan setiap lamaran atau pembaruan CV sudah memenuhi kriteria recruiter secara tuntas. | Digunakan sebagai langkah verifikasi cepat (*QA checklist*) sebelum mengirimkan lamaran. |
