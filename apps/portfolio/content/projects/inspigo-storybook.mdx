## Problem

Inspigo's shared design system had no documentation of its own — no
central place to see what components existed across apps, or how to use
them.

## Architecture

Storybook covering the shared component library reused across multiple
Inspigo apps, not every per-app component — nearly all cross-app
primitives (buttons and similar small pieces especially) ended up with
a story.

## Execution

Own initiative, built and maintained solo. The hard problem was keeping
stories in sync with the real components as they evolved — that
maintenance overhead ultimately won out, and this Storybook instance is
no longer actively updated.

## Impact

Built and drove adoption of Storybook documentation for the shared
component library during its active period. Not presentable outside
Inspigo, and should be read as a past practice rather than an ongoing
one.
